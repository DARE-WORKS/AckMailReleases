# ACKmail Downloads

ACKmail is a desktop email client with optional local AI integration.

| Platform | Download |
| --- | --- |
| Ubuntu, 64-bit Intel or AMD | [Latest Ubuntu release](https://github.com/DARE-WORKS/AckMailReleases/releases/latest) |
| Windows, 64-bit Intel or AMD | [1.0.11 Windows installer preview](https://github.com/DARE-WORKS/AckMailReleases/releases/tag/v1.0.11) |

## Ubuntu

Download the `.deb` and open it in Ubuntu App Center, or install it from the download directory with `sudo apt install ./ackmail-1.0.12-linux-amd64.deb`. The package was tested on Ubuntu 24.04 LTS. Installing it adds the signed ACKmail APT repository for future updates. If you already use 1.0.11, install 1.0.12 once to enable this.

## Windows

The preview is a direct-download `.exe` installer without an Authenticode signature. See the Windows release notes for its test status.

For Codex integration, open ACKmail, select **AI → Connect to ChatGPT Desktop**, then quit and reopen Codex Desktop.

Visit the [ACKmail website](https://ackmail.web.app/) for documentation and product information.
